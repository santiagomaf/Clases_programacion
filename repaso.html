4. while

Repite un bloque mientras una condición sea verdadera. Se usa cuando no sabes de antemano cuántas vueltas harás (o hasta que pase algo). Necesitas que algo cambie dentro del bucle, o será infinito.

5. for y range

Recorre una secuencia (una lista, un texto, un range…) haciendo una vuelta por cada elemento. Se usa cuando sí sabes cuántas veces repetir, o para recorrer todos los elementos de algo.

range(n) genera los números 0, 1, ..., n-1.

Dos for anidados (para recorrer una tabla / tablero):

while vs for: usa for cuando conoces la cantidad de vueltas (ej: "para cada alumno"); usa while cuando dependes de una condición (ej: "hasta que escriba 0").

6. Listas

Una lista guarda varios valores en orden, dentro de [ ]. Cada elemento tiene una posición (índice) que empieza en 0.

append agrega un elemento al final. pop saca (y devuelve) un elemento; sin número saca el último, o le indicas el índice.

8. Funciones

Una función es un bloque de código con nombre que puedes reutilizar. Se define con def. Lo que va entre paréntesis son los parámetros (datos que recibe). return devuelve un resultado.
